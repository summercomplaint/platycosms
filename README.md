# Ten platycosms

Interactive 3D diagrams of the ten closed flat 3-manifolds (Conway and Rossetti's "platycosms"), drawn the way Greg Egan draws
the Hantzsche–Wendt space: a fundamental domain with a coloured tube on every edge (same colour, same edge of the space).

Work in progress; see `PROGRESS.md`. An earlier single-file version is in `legacy/platycosms-v1.html`.

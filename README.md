# Ten platycosms

Interactive 3D diagrams of the ten closed flat 3-manifolds (Conway and Rossetti's "platycosms"), drawn the way Greg Egan draws
the Hantzsche–Wendt space: a fundamental cell with a coloured tube on every edge (same colour, same edge of the space) and
arrowheads for direction. Each space can be seen from outside and from inside, with a fiddler crab in every cell so you can see
how the copies are related. Each is generated by three symmetries, and an animation moves the cell by each of them.
The side panel lists what the paper says (mapping torus, orientable double cover, H₁, Seifert fibrations, and more).
Every fact is sourced in [`NOTES.md`](NOTES.md).

## Run it
```
npm install
npm run dev            # local dev server
npm test               # tiling, Euler characteristic, closed meshes, facts vs generators
npm run build          # static site in dist/
npm run build:single   # one self-contained file: dist-single/index.html (about 3 MB), works from disk or any web host
```
Routes: `#c22`, `#c22/inside`. Spaces: `c1 c2 c3 c4 c6 c22 a1p a1m a2p a2m`.
An earlier single-file version is kept in `legacy/platycosms-v1.html`. Progress and plans are in [`PROGRESS.md`](PROGRESS.md).
